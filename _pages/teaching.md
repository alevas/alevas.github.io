## Julia Programming for Machine Learning

**TU Berlin, [Machine Learning Group](https://web.ml.tu-berlin.de/)** · WiSe 2026/27

An introduction to the Julia language and its machine learning ecosystem. The course teaches students to write reproducible, unit-tested Julia code and to do ML research in Julia. The first half covers the language fundamentals, plotting and DataFrames, classical ML (MLJ.jl), automatic differentiation and deep learning (Flux.jl). The second half is group project work on Julia package development.

I help teach this course.
